    New piece

    Drop files here, or paste an image anywhere. Several photos become the pages of one piece.

    What happens next

    Photos and PDFs of sheet music: pages → parts (your AI model, or OCR) → notes read by homr on this server → MuseScore writes the score and one file per part.

    Guitar and bass tab: photos → your AI model writes out the frets → Guitar Pro → score. A Songsterr link downloads the tracks instead.

    FL Studio projects: each channel with notes becomes a part. You pick a MuseScore instrument for each.

    MusicXML and MIDI go straight through MuseScore.

    Out: .mscz, PDF, audio you can play along with, MusicXML, MIDI and Guitar Pro.

    Studio projects

      Settings

      Saved on the server, so every device sees the same choices.

      AI endpoint

      Reads sheet-music pages (title, instrument names, which pages make up each part, clef and key) and suggests instruments for FL Studio channels. The notes themselves are read by homr, a recognition model that runs inside this app, so they don't depend on the AI.

      Works with any OpenAI-compatible endpoint (and the Ollama, Claude and Gemini APIs). What gets sent: page images (at most 1600 px) and tab photos, plus FL channel names and note ranges when you press Suggest instruments. Nothing else leaves this server. Use a local model to keep it all at home.

      Model for each job (leave empty to use the main model)

      Each Test sends a sample page with a known answer and scores the reply, so you can compare models. Tests use the form as it is now; press Save to keep it.

      For sheet music, pick a model that can read images (a "vision" model). The key is kept on this server in data/settings.json and is never sent back to the browser.

      Favorite instruments

      Favorites appear first in every instrument list. Tap ☆ to add or remove one and ▶ to hear it. The first play of an instrument takes a few seconds while MuseScore renders it.
